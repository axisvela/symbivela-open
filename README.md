# SYMBIVELA Open

Apache-2.0 public contracts, SDKs, examples, documentation, and approved core binaries.

## Contracts

- `contracts/governance-kernel-v1.schema.json`: stable public schema for core human-governance objects.
- `contracts/openapi.yaml`: Governance Kernel HTTP API v1.

## Example

- `examples/governance-kernel/`: trusted-context API usage.

The core implementation lives in `SYMBIVELA` under AGPL-3.0. Enterprise extensions live in `SYMBIVELA-ee` and consume public contracts without copying core source.
